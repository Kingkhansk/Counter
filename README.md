# Counter App

A simple, responsive counter web app built with **HTML, CSS, and JavaScript**.  
Optimized for mobile, tablet, and desktop screens with a clean, modern UI.

## Live Preview

🔗 https://kingkhansk.github.io/Counter/

## Features

- Increment and decrement counter
- Reset counter to zero
- Responsive design using modern CSS
- Smooth animation feedback on count change
- Clean and minimal interface

## Technologies Used

- HTML5 (semantic markup)
- CSS3 (Flexbox, `clamp()`, transitions)
- JavaScript (DOM manipulation)

## Project Structure

Counter/<br>
│<br>
├── index.html<br>
├── style.css<br>

## How It Works

- The counter value is displayed at the center
- `+` button increases the count
- `−` button decreases the count
- `Reset` button sets the counter back to `0`
- Subtle animation provides visual feedback on every update

## Responsive Design

- Font sizes adapt using `clamp()`
- Layout stays centered on all screen sizes
- Buttons are touch-friendly for mobile users

## How to Run Locally

1. Clone or download the repository
2. Open `index.html` in any modern browser
3. Start using the counter

No dependencies. No build steps.
